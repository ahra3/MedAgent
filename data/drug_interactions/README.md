# Drug-Drug Interaction Data

## Source
- **DDInter 2.0**: https://ddinter2.scbdd.com/
- **License**: CC BY-NC-SA 4.0
- **Downloaded**: 08/08/2026

## Files
- `raw/` — Original 8 CSV files from DDInter (by ATC drug category)
- `ddinter_combined.parquet` — Processed & deduplicated (generated by `src/tools/ddinter_loader.py`)
- `common_interactions.json` — Curated fallback dataset of ~28 critical interactions

## Processing
Run `uv run python -m src.tools.ddinter_loader` to process raw CSVs into the Parquet file.

## Columns (processed)
| Column | Description |
|:-------|:------------|
| drug_1 | First drug (original casing) |
| drug_2 | Second drug (original casing) |
| drug_1_normalized | Lowercase, trimmed drug name |
| drug_2_normalized | Lowercase, trimmed drug name |
| severity | Interaction level: major, moderate, minor, unknown |
| mechanism | Pharmacological mechanism |
| management | Clinical management recommendation |
| source_file | Which DDInter CSV file it came from |
